# Pontaj Pro — versiune avansată

PWA statică, fără server și fără cont obligatoriu.

## Funcții noi
- panou de control;
- calendar cu început/sfârșit program și pauză;
- calcul automat al orelor;
- OT 175% în zile lucrătoare / 200% weekend, configurabil;
- CO, CM cu procent per zi, absență și sărbătoare legală;
- bonusuri/rețineri lunare;
- sporuri/bonusuri pe zi;
- statistici lunare și anuale;
- CO rămas;
- tarif orar estimat;
- backup local prin browser;
- instalare ca PWA pe telefon.

## Publicare
Încarcă toate fișierele în GitHub → Settings → Pages → Deploy from branch → `main` / root.
Apoi deschide URL-ul GitHub Pages pe telefon și folosește „Adaugă pe ecranul principal”.

## Atenție
Calculul salarial este estimativ și configurabil. Pentru salarizare oficială trebuie introduse regulile exacte aplicabile contractului și legislației în vigoare. În România, regulile fiscale și de concedii se pot modifica; ANAF publică formularele și instrucțiunile actualizate.
